Práctica 1: entorno Unix/Linux
Anna Mateu Devesa
Fundamentos Computacionales en Biociencias — Universidad Católica de Valencia.

Este repositorio contiene el proyecto de la práctica 1, en la que he trabajado con comandos de Unix/Linux para navegar por directorios, crear y manipular archivos y consultar datos biológicos.

Organización de proyecto_biotec
datos_crudos/: contiene el material de la práctica, con los archivos de muestras, secuencias de ADN y análisis previos, además del archivo notas.txt.

datos_procesados/: contiene el archivo datos_procesados.txt.

scripts/: contiene los archivos de historial de comandos y el archivo scripts.txt.

resultados/: contiene el archivo mis_resultados_finales.txt.

documentacion/: contiene documentacion.txt y tema1.txt. Este último explica qué es el kernel, la diferencia entre shell y terminal y la utilidad de Unix/Linux en bioinformática.
